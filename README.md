## Selected products

### 📝 MCQ Exam Builder

A privacy-conscious assessment tool for educators that imports question banks, validates content, generates shuffled exam versions and produces answer keys.

**Built for:** reducing manual exam preparation across inconsistent Word, Excel and text-based question banks.  
**Engineering focus:** multi-format parsing · validation · document generation · reproducible shuffling · educator UX · privacy-by-design.  
**Status:** deployed and under active development; source remains private while release-quality review is completed.

### 📞 [Voicemail SMS Auto Reply](https://github.com/christosdvm/Voicemail-SMS-Auto-Reply)

A workflow automation system for professional practices that turns voicemail notifications into controlled SMS follow-up within defined operating hours.

**Built for:** reducing missed-call friction without requiring clinicians to interrupt consultations or other professional work.  
**Engineering focus:** Gmail automation · SMS APIs · business-hours logic · duplicate prevention · privacy · operational reliability.

### 📊 Veterinary Logbook & e-Portfolio

A longitudinal competency-tracking framework for veterinary education, designed to evolve from student-level evidence and dashboards into programme-level analytics.

**Built for:** making practical-skills progression more structured, visible and analysable across successive years of training.  
**Product focus:** competency tracking · structured data · dashboards · curriculum analytics · quality assurance.

## Product principles

```text
Start with the workflow, not the technology.
Automate repetitive work without hiding important decisions.
Design for the professional who actually uses the system.
Make privacy and data handling explicit.
Ship → observe → improve.
```

I am interested in software that survives contact with real users — not just prototypes that work in a controlled demo.
